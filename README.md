# Feynman technique to learn topics
Explain ... to me in simplest terms.
Then have me re-explain it back.
Point out gaps, re-teach what I miss and repeat until I can explain it clearly on my own.

# Cheat sheet
Summarize the key concepts of ... on a single page.
Use bullet points, diagrams and examples so I can review it in 5 mins.

# The One-Pager
Compress ... into a single page I can review in 5 minutes.
Include: core concepts, how they connect, common mistakes, and one real example for each.
Make it something I'd actually print and pin on my wall.

# Quiz
Quiz me on the topic ....
Adjust diffculty every 5 questions based on how am I doing so I land in an 85 % success rate.

# The 80/20 Shortcut
I want to learn ... in 20 hours.
Build me a plan that focuses only on what matters most.
Split it into 10 two-hour blocks.
Each block needs: what to learn, one resource, and a quick 15-minute check at the end.

# Teach Me Like I'm New
Explain ... using words a 12-year-old would understand.
No jargon. Use stories and comparisons from daily life. End with 3 questions, if I can't answer them, re-explain until I can.

# The Skill Ladder
Map ... into 5 clear levels.
For each level tell me: what I'll be able to do, what to study, how long it takes, and how I'll know I'm ready for the next step.
Start from "I know nothing" to "I could teach this."

# Beginner Mistakes to Skip
What do people waste time on when learning ...?
Give me the 5 biggest traps beginners fall into, why they happen, and what to do instead.
Save me weeks of going in circles.

# Learn Any Subject Like a World-Class Student
I want to master ....
Create a complete learning system that includes what to learn first, how to practice, how to revise, how to test myself, 
common mistakes beginners make, and milestones to track my progress.

# Create a Personalized Study Plan
I can dedicate [X] hours per day to learning ....
Design a detailed study schedule with weekly goals, daily tasks, revision sessions, quizzes, and practical exercises.

# Understand Complex Topics Easily
Explain ... using simple language, real-world analogies, visual descriptions, and examples.
Then test my understanding with progressively harder questions.

# Build a Learning Habit
Help me build a consistent learning habit for [subject].
Create a daily and weekly routine, recommend effective study techniques, suggest ways to stay motivated, avoid procrastination, and track my progress over time.

# Learn by Doing
Give me 10 practical exercises and mini-projects to help me apply what I learn about ....
Start easy and gradually increase the difficulty.
